# MilkTeaShop – Website đặt đồ uống trực tuyến

MilkTeaShop là dự án học tập xây dựng bằng ASP.NET Core MVC (.NET 8), giúp người dùng xem menu, kiểm tra giá và tình trạng món, đăng ký tài khoản và đặt đồ uống trực tuyến.

## Trải nghiệm website

- [MilkTeaShop – Menu đồ uống trực tuyến](https://milkteashop.onrender.com/)
- [Menu trà sữa MilkTeaShop](https://milkteashop.onrender.com/menu/tra-sua)
- [Hướng dẫn đặt trà sữa online](https://milkteashop.onrender.com/huong-dan/dat-hang)

## Các chức năng chính

- Xem danh sách đồ uống theo danh mục.
- Xem giá và tình trạng còn hàng.
- Đăng ký, đăng nhập tài khoản khách hàng.
- Tùy chỉnh size, đường, đá, topping và số lượng khi đặt món.
- Theo dõi đơn hàng trong tài khoản.

## Nội dung SEO đã triển khai

- Viết title và meta description riêng cho các trang nội dung chính.
- Sắp xếp heading H1, H2, H3.
- Bổ sung liên kết nội bộ giữa trang chủ, menu và hướng dẫn đặt hàng.
- Tạo URL dễ đọc, canonical và sitemap XML.

## Công nghệ

ASP.NET Core MVC · .NET 8 · Entity Framework Core · SQLite · Bootstrap · Docker · Render
